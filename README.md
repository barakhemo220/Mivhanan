# מערכת "מבחנן" (Mivhanan)
## פלטפורמת מבחנים תקופתיים במכשור ובקרה תעשייתית

מערכת ווב מתקדמת לבחינה והסמכה תקופתית של עובדים וטכנאי מכשור ובקרה.
המערכת נבנתה בארכיטקטורת **Node.js (Express)** ו-**React (Vite)**, בעלת תמיכה מלאה בעברית (RTL), עיצוב Glassmorphism טכנולוגי יוקרתי, ותרשימים טכניים אינטראקטיביים.

---

## 🚀 הוראות הפעלה מהירות

המערכת דורשת סביבת **Node.js** (גרסה 18 ומעלה).

### 1. הפעלת שרת ה-Backend
פתחו חלון טרמינל והריצו:
```powershell
cd backend
npm install
npm start
```
השרת יעלה בכתובת: `http://localhost:5000`

### 2. הפעלת ממשק ה-Frontend
בחלון טרמינל נוסף הריצו:
```powershell
cd frontend
npm install
npm run dev
```
הממשק ייפתח בדפדפן בכתובת: `http://localhost:5173`

## ⚙️ יכולות מרכזיות במערכת

1. **אימות עובדים מאובטח**:
   - התאמת שם מלא ומספר אישי מול קובץ נתוני עובדים.
   - מנגנון בחירה מהירה (Quick Profile Chips) לבדיקה מהירה.
2. **מנוע מבחן אקראי**:
   - הגרלה רנדומלית של שאלות מתוך בנק השאלות (`backend/data/questions.json`).
   - הגנה מפני העתקות: התשובות וההסברים אינם נשלחים לדפדפן של הנבחן במהלך הבחינה אלא מחושבים אך ורק בשרת בהגשה.
3. **ממשק נבחן אינטואיטיבי**:
   - **ניווט חופשי**: מעבר קדימה ואחורה בין השאלות בכל שלב.
   - **גריד שאלות (Question Matrix)**: לוח מקשים צדדי המציג חיווי בזמן אמת לשאלות שנענו, שאלות שטרם נענו, והשאלה הנוכחית.
   - **סימון דגלים (Flag for Review)**: אפשרות לסמן שאלה לבדיקה חוזרת לפני הגשה.
   - **חסינות לניתוק / רענון**: שמירת מצב מקומית (State Persistence) כך שרענון דפדפן אינו מאפס את התשובות.
   - **תרשימים טכניים מוגדלים (Lightbox Zoom)**: כל שאלה כוללת תרשים טכני מדויק (דיסקת צמצם, RTD 3-חוטים, שסתום בקרה פנאומטי, אות HART FSK, בקר PID, מדידת מפלס Wet Leg, מתמר I/P, מד ספיקה מגנטי, רמות SIL ותרשים P&ID לפי תקן ISA 5.1). לחיצה על התרשים פותחת תצוגה מוגדלת ברורה.
4. **תחקיר ומשוב מקצועי בסיום**:
   - חישוב ציון מיידי (0-100%).
   - חיווי סטטוס עבר / נכשל (רף מעבר: 70%).
   - תחקיר מעמיק של כל שאלה: הצגת בחירת העובד מול התשובה הנכונה, וקריאת **הסבר טכני מפורט** המסביר את העקרון הפיזיקלי, התקן והמשוואות.
   - כפתור הדפסה / שמירה כ-PDF של גיליון הציונים.
5. **מסך מנהל / בוחן (Admin Dashboard)**:
   - מדדי ביצוע (KPIs): סה"כ מבחנים שהוגשו, אחוז מעבר, ציון ממוצע, כמות שאלות ועובדים.
   - יומן תוצאות חי עם חיפוש עובדים, סינון עברו/נכשלו, ופירוט תאריכים וזמנים.
   - **ייצוא לאקסל בלחיצת כפתור**: קובץ CSV עם קידוד UTF-8 BOM מובנה הנפתח ישירות בעברית תקינה ב-Microsoft Excel.
   - סייר בנק השאלות ואפשרות הוספת שאלה חדשה דרך ממשק ייעודי.
   - ניהול רשימת עובדים והוספת עובדים חדשים.
