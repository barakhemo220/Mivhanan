# מערכת "מבחנן" (Mivhanan)

## פלטפורמת מבחנים תקופתיים במכשור ובקרה תעשייתית

מערכת ווב מתקדמת לבחינה והסמכה תקופתית של עובדים וטכנאי מכשור ובקרה.
המערכת נבנתה בארכיטקטורת **Node.js (Express)** ו-**React (Vite)**, מחוברת למסד נתונים בענן **MongoDB Atlas**, בעלת תמיכה מלאה בעברית (RTL), עמידה קפדנית בחוק הגנת הפרטיות, עיצוב Glassmorphism טכנולוגי יוקרתי, ותרשימים טכניים אינטראקטיביים.

---

## 🚀 הוראות הפעלה מהירות

המערכת דורשת סביבת **Node.js** (גרסה 18 ומעלה).

### 1. הפעלת שרת ה-Backend

פתחו חלון טרמינל והריצו:

```powershell
cd backend
npm install
npm start
```

השרת יעלה בכתובת: `http://localhost:5000`

### 2. הפעלת ממשק ה-Frontend

בחלון טרמינל נוסף הריצו:

```powershell
cd frontend
npm install
npm run dev
```

הממשק ייפתח בדפדפן בכתובת: `http://localhost:5173`

## ⚙️ יכולות מרכזיות במערכת

1. **אימות עובדים מאובטח ועמידה בחוק הגנת הפרטיות**:
   - התאמת שם משתמש וסיסמה חזקה מול מסד הנתונים בענן MongoDB Atlas.
   - אבטחת פרטיות מלאה – שמות אנונימיים וללא שמירת מספרי זהות.
2. **מנוע מבחן אקראי מתוך 361 שאלות**:
   - הגרלה רנדומלית של 20 שאלות מקצועיות מתוך מאגר מקיף של 361 שאלות מכשור ובקרה.
   - הגנה מפני העתקות: התשובות וההסברים אינם נשלחים לדפדפן של הנבחן במהלך הבחינה אלא מחושבים אך ורק בשרת בהגשה.
3. **ממשק נבחן אינטואיטיבי**:
   - **ניווט חופשי**: מעבר קדימה ואחורה בין השאלות בכל שלב.
   - **גריד שאלות (Question Matrix)**: לוח מקשים צדדי המציג חיווי בזמן אמת לשאלות שנענו, שאלות שטרם נענו, והשאלה הנוכחית.
   - **סימון דגלים (Flag for Review)**: אפשרות לסמן שאלה לבדיקה חוזרת לפני הגשה.
   - **חסינות לניתוק / רענון**: שמירת מצב מקומית (State Persistence) כך שרענון דפדפן אינו מאפס את התשובות.
   - **תרשימים טכניים מוגדלים (Lightbox Zoom)**: שאלות הכוללות תרשימים טכניים מציגות תצוגה מוגדלת ברורה וחדה בלחיצה.
4. **תחקיר ומשוב מקצועי בסיום**:
   - חישוב ציון מיידי (0-100%).
   - חיווי סטטוס עבר / נכשל (רף מעבר: 70%).
   - תחקיר מעמיק של כל שאלה: הצגת בחירת העובד מול התשובה הנכונה, וקריאת **הסבר טכני מפורט**.
   - שמירה והדפסה אוטומטית כ-PDF של גיליון הציונים והתחקיר.
5. **מסך מנהל / בוחן (Admin Dashboard)**:
   - מדדי ביצוע (KPIs): סה"כ מבחנים שהוגשו, אחוז מעבר, ציון ממוצע, כמות שאלות במאגר (361) ועובדים (38).
   - יומן תוצאות חי עם חיפוש עובדים, סינון עברו/נכשלו, אפשרות מחיקת תוצאות שגויות, ופירוט תאריכים וזמנים.
   - **ייצוא לאקסל בלחיצת כפתור**: קובץ CSV עם קידוד UTF-8 BOM מובנה הנפתח ישירות בעברית תקינה ב-Microsoft Excel.
   - ניהול וצפייה במאגר השאלות המלא לפי נושאים ורמות קושי.
   - ניהול רשימת עובדים, צפייה בסיסמאות לצורכי הדרכה, זימון מועדי בחינה ותיעוד הערות.
